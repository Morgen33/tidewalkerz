# TideWalkerz

Official landing site for **TideWalkerz** — a Solana NFT collection of 1,100 figurative artworks embodying a unified force, moving with the inevitability and power of an unstoppable wave of change.

Built for founder [@Blessedsam080](https://twitter.com/Blessedsam080) and the TideWalkerz community.

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Three.js interactive wave shader

## Local development

```sh
npm i
npm run dev
```

```sh
npm run build   # production build
npm run preview # preview production build
```
