# TideWalkerz

Official landing site for **TideWalkerz** — a Solana NFT collection of 1,100 figurative artworks embodying a unified force, moving with the inevitability and power of an unstoppable wave of change.

An NFT collection on Solana founded by [Blessed Sam](https://twitter.com/Blessedsam080).

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Three.js interactive wave shader
- GSAP

## Local development

```sh
npm i
npm run dev
```

```sh
npm run build   # production build
npm run preview # preview production build
```
